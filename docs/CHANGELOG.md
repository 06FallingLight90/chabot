# 更新日志

## 2026-08-07

### 新增
- **API 配置预设**：设置页接口配置区新增「预设配置」，可保存/覆盖/删除至多 3 套 API 配置（接口地址/API Key/模型/温度），点击预设一键填充并快速切换；「保存当前为预设」通过 ActionSheet 选择槽位，接口地址匹配供应商预设时自动取名
- **L2 情景记忆 = 约定清单（TODO）**：记忆指南明确 L2 主要维护与用户的约定/待办（如"约定今晚8点一起打游戏"），新约定立即新增、完成/取消/变化立即用修改/删除更新，保证清单始终反映最新约定
- **L3 临时记忆快速迭代**：记忆指南强化 L3 定位为近期琐事与临时状态，过时立即修改或删除旧项，不堆积过时信息
- **会话独立记忆与人格**：记忆、人格设置（人格/自定义提示词/情景时间模式）按会话独立存储，切换历史会话即切换对应记忆与人格
- **情景按会话独立**：情景历史（`scenes`）随会话独立，切换会话情景不串台；旧版全局情景首次启动自动迁移到首个会话
- **复制对话/记忆**：历史弹窗新增「复制对话到新会话」（消息+记忆+概要+人格+情景，标题带"副本"后缀）与「复制记忆到新会话」（仅记忆+人格快照），快速复用已有上下文

### 变更
- **记忆指南层级化**：`MEMORY_GUIDE` 由"触发条件"改为按 L1/L2/L3 分层说明用途与维护频率；修改/删除操作优先级高于新增
- **版本号升级**：`manifest.json` 1.0.6 → 1.0.7

### 修复
- **Ollama 本地模型无返回**：Ollama 的 `/v1/chat/completions` 兼容接口默认 `stream=true`（SSE 流式），与 OpenAI 默认非流式不同，导致 App 按非流式 JSON 解析不到内容。现请求体显式传 `stream:false`，强制 Ollama 返回标准 JSON，无需 App 支持流式解析；接口预设新增「Ollama(本地)」一键填入，响应格式异常日志附实际响应体便于排查

## 2026-08-05

### 新增
- **历史对话与会话管理**：对话存储从单流改为多会话模型（`chabot_conversations`），聊天页头部新增「新对话」「历史」入口；历史弹窗可切换会话、删除会话（删当前自动切最近），会话标题自动取首条用户消息，旧版单流数据首次启动自动迁移为第一个会话
- **上下文压缩**：将上文交由 LLM 压缩为精炼概要（保留关键事实/偏好/决定/进行中的事），后续请求只发送「概要 + 未压缩尾部」，精简上下文并减少 token 消耗；超 80 条自动分批、逐批合并概要；历史消息仍完整保留可翻阅
- **自动压缩间隔设置**：设置页可选 关闭/20/30/40/60/80 条，累计新增消息达到阈值后每轮回复末尾自动异步压缩（不阻塞回复展示）
- **调试日志面板**：设置页新增调试日志，记录每次 LLM 请求（完整 messages JSON）、响应（完整返回内容）、错误及关键操作（发送/会话/压缩/记忆/情景/保存设置），支持点击展开完整详情、刷新与一键清空；环形缓冲 200 条
- **情景历史记录**：情景存储改为最多 10 条 FIFO 历史，系统提示词注入「情景变化」序列，帮助 LLM 理解情景过渡，衔接更流畅
- **一键回到底部按钮**：聊天页右下角浮动按钮，仅当用户上翻离开底部时出现（`scrollTop` 差值 + 触摸方向双检测），点击动画滚回最新消息
- **情景历史查看**：情景编辑弹窗展示最近 10 条历史情景（最新在前），点击任意条目填入编辑框复用
- **压缩日志含完整概要**：调试日志中「压缩上文」条目详情附完整压缩后上文全文，可展开核对压缩结果

### 修复
- **日志展开无效**：收起态改用 JS 截断（前 200 字符预览）替代 `-webkit-line-clamp`（部分 WebView 无法释放截断），展开后可靠显示完整请求/返回内容
- **回到底部按钮点击无效**：`scroll-into-view` 仅在值变化时触发滚动，按钮复用时值未变导致静默失效；改为先清空再赋值
- **测试时序抖动**：记忆检索测试因同毫秒 `created_at` 并列导致"最近记忆"槽位选择不稳定，补回数据前加 10ms 延时使断言稳定

### 变更
- **对话存储键迁移**：对话从 `chabot_chat_history` 迁移至 `chabot_conversations`（会话数组）+ `chabot_active_conv`（当前会话 id）；旧键首次启动自动迁移，此后不再写入
- **重新生成走截断接口**：`popLastAssistant` 改用存储层 `truncateChat`，与多会话模型对齐
- **版本号升级**：`manifest.json` 1.0.5 → 1.0.6

## 2026-08-04

### 新增
- **重新生成按钮**：最新一条 AI 回复下方出现"重新生成"按钮，点击后移除该条回复并以相同输入重新请求 LLM，重生成同样走完整记忆/情景链路
- **情景描述去文学化**：情景指南改为中性事实记录（"深夜，用户在卧室准备考研"），禁止文学化描写
- **侧边滑块跟踪滚动位置**：滑块拇指现在实时跟随 scroll-view 滚动位置，不再仅在拖拽时显示
- **LLM 返回格式双向加固**：提示词新增反例对比（`Memory: user_fact: xxx` 等常见错误），解析层兼容全角→箭头、`category: content` 冒号分隔、Scene 行自动清洗引号/标点

### 修复
- **响应延迟问题**：三份内置指南（记忆/情景/对话规则）从 ~1200 字压缩到 ~335 字，每轮减少约 150 prompt tokens
- **滑块 thumb 常驻顶部问题**：~~新增 `@scroll` 事件 + `scrollRatio` 实时计算~~ App 端 scroll-view 的 `@scroll` 事件不返回 `scrollHeight`/`clientHeight`，导致 `scrollRatio` 恒为初始值。改为纯拖拽驱动：`dragRatio` 松手后保留在当前位置，发送新消息时自动重置为底部。移除 `@scroll` 和 `scrollRatio`
- **LLM 格式不规范导致漏解析**：Memory 行解析兼容 `category: content` 冒号格式和全角 `→` 箭头，Scene 行自动去除引号/末尾标点

## 2026-08-03

### 新增
- **记忆修改/删除操作**：LLM 可通过 `Memory: 修改 原内容 → 新内容` 和 `Memory: 删除 原内容` 格式修改或删除已有记忆，按内容逐字匹配
- **LLM 驱动情景记录**：每次对话 LLM 输出 `Scene:` 行记录当前情景（谁在哪做什么），聊天页顶部情景条展示，点击可查看/修改
- **情景时间模式**：设置中可选择"现实时间"（注入真实日期时间供情景判断）或"虚拟时间"（不发送时间，适合角色扮演）
- **侧边滑块**：聊天记录超过 15 条时右侧出现垂直滑块，按住拖动按比例快速定位到任意消息
- **手动编辑记忆级别**：记忆页编辑弹窗增加 L1/L2/L3 级别切换按钮，保存时沿用一致性兜底
- **聊天背景图片**：设置页可选择相册图片作为聊天背景，App端压缩后持久化到文件，H5端 canvas 压缩为 base64 避免 localStorage 配额超限

### 修复
- **持久化数据丢失**：App端 `plus.sqlite` 的 `openDatabase`/`selectSql` 为异步回调 API，与同步接口不匹配，导致启动时读取为空、后续全量重写清空数据。改为统一使用 `uni.setStorageSync` 同步存储，三端可靠
- **背景图不随聊天滚动**：背景从 `.page` 移到 scroll-view 可视区（`:style` 绑到 scroll-view），不随内容拉伸
- **背景图 H5 配额超限**：`uni.compressImage` 仅 App/小程序可用，H5 改用 canvas 压缩（限宽 1080px、JPEG 0.8）
- **记忆写入极少**：记忆指南从"只在重要新信息时"改为"宁多勿漏"的五类触发场景 + 输入→输出示例，LLM 遵循率大幅提升

### 优化
- **自定义人格字数扩容**：`textarea` 显式设置 `maxlength="5000"`，支持千字级人格提示词，新增字数统计
- **对话规则去保守化**：从"剩余不输出"改为"只有纯闲聊才跳过"，放宽记忆写入触发

### 变更
- **持久化层简化**：移除 `plus.sqlite` 分支（含全部条件编译代码），统一 `uni.setStorageSync`。历史 sqlite 数据因异步 API bug 从未正确读写，实际无数据丢失

## 项目初始化

- 基于 uni-app (Vue 3) 的轻量 LLM 人格聊天 App，无后端、纯端侧
- **记忆系统**（移植自 koishi-ai-pet）：SQLite 记忆持久化 → L1/L2/L3 三级分级、半衰期衰减、关键词+轻量文本相似度去重合并、召回冷却、MMR 分层检索、容量淘汰/L3过期清理/L2降级维护
- **LLM 驱动记忆**：system prompt 内置记忆指南，LLM 输出结构化 `Memory:` 行 → App 解析入库
- **人格系统**：4 个预设（温柔大姐姐/元气学妹/古明地恋/毒舌傲娇猫娘）+ 自定义
- **跨端兼容**：三页 tabBar（聊天/记忆/设置），App + H5 + 微信小程序
- 编写 `CLAUDE.md` 项目协作文档与 `npm test` 核心逻辑测试
